# Multiplayer Dungeon Game
Simple in browser multiplayer dungeon game.

## Local Instructions

1. git clone https://github.com/TommyDong1998/MultiplayerDungeon
2. cd MultiplayerDungeon
3. npm install
4. npm run start
5. open http://localhost:8080 or http://localhost: environment port

## Elastic Beanstalk Deployment

1. Download as [zip](https://github.com/TommyDong1998/MultiplayerDungeon/archive/refs/heads/main.zip)
2. Upload and deploy
3. Up and running :)
